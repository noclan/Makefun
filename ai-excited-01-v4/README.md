# The Ant and the Skyscraper

A tiny red ant hoists an entire glass skyscraper overhead at golden hour.

The idea is scale inversion: the smallest creature doing the biggest possible
feat. One huge diagonal tower gives the picture its momentum, and the ant
braced underneath it, mandibles gripping the base, is the surprise — a hero
you almost miss at first glance, doing something impossible. It reads clearly
even at thumbnail size, because the whole image is one diagonal shape plus a
sun flare.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` into the output directory, byte for byte. Running it
twice produces identical output.
